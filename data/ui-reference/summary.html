📝 月度汇总怎么用

1. 本页无需填写，数字全部根据「订单台账」和「收支明细」自动计算。

2. 最上面的「全程总账」是从你登记的第一笔账算到此时此刻的累计数，每记一笔就会自动更新。

3. 总采购成本 = 布料 + 耗材辅料 + 工具；总发货运费 = 每周合并发货运费；总收入 = 定金 + 尾款。

4. 净利润 = 总收入 −（采购成本 + 运费），绿色为盈利、红色为亏损。

5. 订单情况显示当月新增订单、已完成订单、月末待收尾款合计。

6. 想留档或发给别人，点底部「导出 Excel」下载 .xlsx 文件。
