📝 订单台账怎么用

1. 客户下单就点底部「+ 记一笔订单」，先填日期、订单编号、客户、款式、报价。

2. 收到钱才更新「已收定金」「已收尾款」——只填实际到账的金额，没收到就填 0。

3. 待收尾款 = 报价 − 定金 − 尾款 − 抹零，自动算，不用管；数字大于 0 会自动亮黄提示。

4. 订单状态只有三个，按下拉选：已收定金-待制作 → 已收尾款-待发货 → 已完成。

5. 客人尾款抹零头时，把抹掉的金额填进「抹零/优惠」，订单就能正常结清，利润统计也准确。

6. 同一笔定金/尾款记得在「收支明细」也记一行，两页才对得上。

📷 成品照片 & 订单截图

7. 做好一个包就在编辑订单里「成品照片」传几张，会存进这单里，列表上能看到缩略图，点一下放大。

8. 要收尾款时，点订单右边的 📸（或在编辑页点「生成订单截图」），会生成一张订单详情图：客户、编号、款式、金额、待补尾款、成品照片都在上面。

9. 点「保存到相册」存进手机相册，再把图发给客人确认。若没自动存进相册，可长按图片选「保存图片」。

10. 图片存不下来、或想直接发文字，可以点「复制文字版」，粘到微信发给她。

📝 收支明细怎么用

1. 每一笔真实现金流记一行：买一次布一行、收到定金一行、尾款一行。

2. 支出填「支出金额」，收入填「收入金额」，全部填正数，同一行只填一边。

3. 收入永远填实际到账的钱。客人尾款抹掉零头、实付 41 就填 41；差的那 0.7 回到订单里填「抹零/优惠」，账就平了。

4. 运费规则：不用每个包裹单独记！每周发货结束，把这周快递总运费记 1 行，说明写「第几周，共 XX 个包裹」。

5. 买布、辅料、工具都算支出；贵的工具在备注里写明，一次性计入当月成本。

6. 退款/退货在备注注明，并从对应收入中冲减，避免利润虚高。

📝 月度汇总怎么用

1. 本页无需填写，数字全部根据「订单台账」和「收支明细」自动计算。

2. 最上面的「全程总账」是从你登记的第一笔账算到此时此刻的累计数，每记一笔就会自动更新。

3. 总采购成本 = 布料 + 耗材辅料 + 工具；总发货运费 = 每周合并发货运费；总收入 = 定金 + 尾款。

4. 净利润 = 总收入 −（采购成本 + 运费），绿色为盈利、红色为亏损。

5. 订单情况显示当月新增订单、已完成订单、月末待收尾款合计。

6. 想留档或发给别人，点底部「导出 Excel」下载 .xlsx 文件。
